# 🤏 Mudra

**Бесконтактное управление курсором через веб-камеру.** Указательный палец — мышь. Щипок — клик. Долгий щипок со сдвигом — перетаскивание.

Лёгкий, быстрый и полностью локальный аналог Leap Motion / Apple Vision Pro — но на обычной веб-камере ноутбука. Никаких внешних сенсоров, никаких облачных сервисов.

---

## ✨ Возможности

- 🖱️ **Управление курсором** — указательный палец ведёт мышь по экрану
- 🤏 **Клик щипком** — соединение большого и указательного пальцев
- ✊ **Drag-and-drop** — удержание щипка + сдвиг перетаскивает окна, файлы, выделяет текст
- 🎯 **Точная наводка** — гибридный трекинг (ладонь + смещение кончика) и One Euro Filter
- 🧲 **Dead zone** — курсор не дрожит, когда рука стоит на месте
- 📐 **Инвариантность к дистанции** — жест распознаётся одинаково с 30 см и с 1.5 м
- ⚡ **60 FPS**, `BUFFERSIZE=1` — минимальная задержка между рукой и курсором
- 🪟 **Windows-ready** — обход DPI-скейлинга и `UAC`-ограничений

## 🚀 Установка

### Требования

- **Python 3.12** (для `mediapipe==0.10.14` нет колёс под 3.13)
- Windows / macOS / Linux
- Веб-камера (встроенная в ноутбук подойдёт)

### Через `uv` (рекомендуется)

```bash
uv init mudra
cd mudra

# Зафиксировать Python 3.12 (в pyproject.toml поменять requires-python на ">=3.12")
uv python pin 3.12

uv add "mediapipe==0.10.14" opencv-python pyautogui
```

### Через `pip`

```bash
python3.12 -m venv .venv
.venv\Scripts\activate       # Windows
# source .venv/bin/activate  # macOS / Linux

pip install "mediapipe==0.10.14" opencv-python pyautogui
```

## 🏃 Запуск

```bash
uv run main.py
# или
python main.py
```

Откроется окно с видеопотоком и скелетом руки. Водите указательным пальцем — курсор следует за ним. **ESC** в окне камеры — выход.

## 🖐️ Жесты

| Жест | Действие |
|------|----------|
| Указательный палец | Движение курсора |
| Быстрый щипок (большой + указательный) | Левый клик |
| Щипок → удержание → сдвиг | Перетаскивание (drag-and-drop) |
| Разжать пальцы | Отпустить перетаскиваемый объект |

Пороги щипка **нормированы на размер ладони**, поэтому жест работает на любой дистанции от камеры.

## ⚙️ Тюнинг параметров

Все настройки — в начале `main.py`. Основные:

### Плавность и отзывчивость

| Параметр | По умолчанию | Что делает |
|----------|:-:|-------------|
| `PALM_MINCUTOFF` | `0.025` | Сглаживание ладони (↓ = плавнее, ↑ = отзывчивее) |
| `PALM_BETA` | `0.5` | Реакция ладони на быстрые движения |
| `OFFSET_MINCUTOFF` | `0.12` | Сглаживание точной наводки кончика |
| `OFFSET_BETA` | `1.2` | Отзывчивость кончика при резких движениях |
| `DEAD_ZONE_PX` | `2.5` | Мёртвая зона против микродрожания |

### Логика жестов

| Параметр | По умолчанию | Что делает |
|----------|:-:|-------------|
| `PINCH_RATIO_THRESH` | `0.35` | Порог срабатывания щипка (↓ = строже) |
| `DRAG_HOLD_TIME` | `0.30` | Сколько держать щипок до разрешения drag |
| `DRAG_MOVE_THRESHOLD` | `60` | Минимальный сдвиг (px) для старта drag |

### Рецепты

- 🐢 **Курсор слишком вязкий** → поднимите `PALM_BETA` до `0.8`, `OFFSET_BETA` до `1.8`
- 🐇 **Курсор дрожит** → опустите `PALM_MINCUTOFF` до `0.015`, `DEAD_ZONE_PX` до `3.5`
- 🎯 **Не попасть по мелким иконкам** → `OFFSET_MINCUTOFF` до `0.08`
- 🤏 **Ложные клики** → `PINCH_RATIO_THRESH` до `0.28`
- ✊ **Drag срабатывает слишком легко** → `DRAG_HOLD_TIME` до `0.4`, `DRAG_MOVE_THRESHOLD` до `80`

### Тумблеры

```python
USE_PALM_HYBRID     = True   # гибридный трекинг ладонь + кончик
USE_DEAD_ZONE       = True   # мёртвая зона
PRECISION_ON_PINCH  = True   # усиленная фильтрация в момент щипка
DEBUG_OVERLAY       = True   # скелет, FPS, статус (поставьте False для "продакшена")
```

## 🧠 Как это работает

### 1. Распознавание руки
MediaPipe Hands выдаёт 21 ключевую точку кисти в нормализованном виде (0.0–1.0) на каждом кадре.

### 2. Гибридный трекинг (главный секрет стабильности)
Кончик указательного пальца дрожит сильнее всего. Поэтому курсор считается как:

```
курсор = сглаженная_ладонь + сглаженное_смещение_кончика
```

- **Ладонь** (среднее 5 стабильных точек: запястье + 4 MCP) фильтруется **агрессивно** — она движется крупными мазками
- **Смещение кончика от ладони** фильтруется **мягко** — это точная наводка, её надо отдавать без лага

### 3. One Euro Filter
Адаптивный ФНЧ: сильно сглаживает медленные движения (прицеливание), пропускает быстрые (взмахи) без задержки. Пять независимых фильтров — на ладонь X/Y, смещение X/Y и прямой канал (fallback).

### 4. Нормированный порог щипка
```
pinch_ratio = расстояние(большой, указательный) / размер_ладони
is_pinching = pinch_ratio < 0.35
```
Инварианта к дистанции до камеры — работает и в 30 см, и в 1.5 м.

### 5. Drag-and-drop
- Короткий щипок без движения → клик
- Щипок удержан `> 0.30` с **и** палец сдвинулся `> 60 px` → `mouseDown` + перетаскивание
- Отпускание пальцев → `mouseUp`

### 6. Защита от «залипания» мыши
Если рука пропала из кадра или drag остался активен без щипка — принудительный `mouseUp()`. Мышь не застрянет в нажатом состоянии.

## 🛠️ Решение проблем

### `AttributeError: module 'mediapipe' has no attribute 'solutions'`
Вы на Python 3.13+. Откатитесь на Python 3.12 и `mediapipe==0.10.14`:

```bash
uv python pin 3.12
uv add "mediapipe==0.10.14"
```

Проверьте, что в `pyproject.toml` стоит `requires-python = ">=3.12"`.

### Курсор не долетает до краёв экрана
На Windows включено DPI-масштабирование. Убедитесь, что в коде есть:
```python
ctypes.windll.user32.SetProcessDPIAware()
```

### Скрипт не управляет мышью в окнах администратора
Запустите терминал/IDE **от имени администратора** — Windows UAC блокирует инъекции в привилегированные процессы.

### Камера выдаёт 30 FPS вместо 60
Не все веб-камеры поддерживают 720p60. Проверьте `actual_fps` в консоли при старте. При 30 FPS всё работает, просто чуть менее отзывчиво.

### Курсор «пролетает» дугой при возврате руки в кадр
Включён сброс фильтров (`REACQUIRE_RESET = 10`). Если хотите плавный «свуп» обратно — увеличьте значение до `30–60`.
